# WP Bench auf dem S23 – ohne PC

1. Auf dem S23 im Browser öffnen (bei GitHub angemeldet):
   https://github.com/Pablito-Judo/einQuantumtrost/releases/tag/bench-latest
2. `wp-bench.apk` antippen → herunterladen → öffnen → „Installation aus dieser Quelle erlauben“ → Installieren.
3. App „WP Bench“ öffnen, Benachrichtigungen erlauben.
4. Ladekabel anstecken, WLAN an (lädt einmalig ca. 13 GB Modelle von Hugging Face).
5. Oben **„▶ ALLES AUTOMATISCH“** drücken. Handy liegen lassen (Bildschirm bleibt dunkel-gedimmt an, geht später von selbst aus).
6. Nach ca. 10–12 h (morgens): App öffnen → **„CSV teilen“** → an Claude schicken.

Fertig. Alles andere macht die App selbst.
